# SRF

https://xenoah.github.io/games/skyracers-fpv/skyracers-fpv.html

Three.js ベースの FPV ドローンレース風ミニゲームです。

## Files

- `skyracers-fpv.html`: ゲーム本体の画面と UI
- `js/error-handler.js`: エラー表示
- `js/drone-data.js`: ドローンやゲームデータ
- `js/game.js`: ゲームロジックと 3D 描画
- `assets/textures/`: コース用テクスチャ
- `srf_readme.md`: このファイル

## Notes

静的ファイルだけで動作します。公開時は `games/skyracers-fpv/skyracers-fpv.html` を入口にします。
