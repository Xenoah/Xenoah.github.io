HTML Editor

記事フォルダごと書き出して、置くだけで公開。

`blog/articles/YYYY-MM-DD-slug/` に `index.html` と画像をまとめると、GitHub Pagesが自動でブログ記事として表示します。

1. 書く HTML本文、画像管理、プレビューをこの画面でまとめます。
2. フォルダ出力 `index.html` と画像入りの記事フォルダZIPを書き出します。
3. 配置 解凍した記事フォルダを `blog/articles` に置くと公開されます。

画像

画像を選ぶとここに並びます。

画像はZIP内で `index.html` と同じ記事フォルダに入ります。本文には `` として `/blog/articles/.../image.png` の形で挿入されます。

HTML取り込み

貼り付けたHTMLを本文へ取り込みます。script/styleやイベント属性は除去します。

公開前チェック

    GitHubへ直接アップロード

    手動配置だけで運用できます。直接アップロードは `index.html` と選択中の画像を同じ記事フォルダへ送ります。
