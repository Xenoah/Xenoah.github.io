# ブログ記事エディター

サイトの `/blog/editor.html` から開きます。これまでと同じJekyllの `blog` レイアウトを使用します。

## 書く

1. 「記事タイトル」と本文を、そのまま入力します。Enterは段落、Shift + Enterは改行です。
2. 文字を選び、ツールバーで太字・斜体・下線・取り消し線・マーカー・リンクを設定します。「本文」のメニューから大見出し・小見出し・引用・コードへ切り替えられます。
3. 画像はツールバーの「画像」、貼り付け、本文へのドラッグ＆ドロップで挿入できます。画像下にキャプションを入力でき、画像をクリックすると説明文・表示幅を変更できます。
4. 「カバー画像を追加」で記事の表紙を設定します。画像ライブラリから選ぶこともできます。
5. 「動画」にYouTubeのURLを入れると、記事内に埋め込めます。動画にフォーカスしてDeleteで削除できます。
6. 右側で公開日・タグ・説明文・URL末尾を設定します。英語のタイトルと説明、カバー画像のURLは「その他の設定」にあります。
7. 「プレビュー」で公開時のレイアウトを確認します。「HTML」では本文のソースを直接編集できます。

「元に戻す／やり直す」は本文の編集と画像の挿入・削除に対応します。記事情報の入力欄では通常のテキスト入力の履歴を使います。

本文を右クリックすると、文字装飾・見出し・リンク・画像挿入・履歴のメニューを開けます。画像の右クリックではカバー設定・説明とサイズ・削除を選べます。矢印キーで移動、Enterで実行、Escで閉じます。Shift＋右クリックでブラウザ標準のメニューを使えます。貼り付けはブラウザの許可が必要です。

## 下書きと既存記事

- 本文・記事情報・追加した画像を、このブラウザのIndexedDBに自動保存します。次に開くと前回の下書きを復元します。旧エディターの下書きも読み込めます。
- 下書きは1記事分です。「新しい記事」「記事の置き換え」を使う前に、残したい記事をZIPで保存してください。
- 保存できない場合は画面に表示します。本文だけ保存できた場合、画像はZIPで保管してください。ブラウザのデータ削除や別端末への移動にはZIPを使います。
- 「記事を開く」→「記事フォルダを選ぶ」で、フォルダ直下の `index.html` と画像を一緒に読み込みます。HTMLファイルだけの読み込み、HTMLの貼り付けも使えます。
- 日付・URL末尾を変更すると、ライブラリにある画像の出力パスも更新します。外部URLの画像はリンク先を参照し続けます。

## 書き出す

「書き出す」→「画像込みZIPをダウンロード」で、次のフォルダを保存します。

    YYYY-MM-DD-slug/
      index.html
      画像ファイル

解凍したフォルダを `blog/articles/` に配置します。出力は既存記事と同じfront matter（`layout: post`、`blog_article: true`、公開URL、記事情報）とHTML本文です。公開URLは `/blog/YYYY/MM/DD/slug/` になります。

対応ブラウザでは「フォルダへ保存」も使えます。HTMLのみのダウンロード、HTML・公開URL・フォルダ構成のコピーは「ほかの書き出し方法」にあります。書き出し操作だけでは公開されません。

## 開発・検証

実行時の外部ライブラリやCDNへの依存はありません。`editor.css` はエディターだけで読み込み、記事のスタイルは既存の `blog.css` を利用します。

    cd blog
    npm ci
    npm test

テストにはNode.js、npm、Pythonが必要です。DOMテストは記事の読み書き、画像参照、保存・復元、HTMLの除染とZIPの互換性を検証します。ブラウザ固有の文字装飾・日本語IME・ドラッグ操作と画面レイアウトは、実ブラウザで別途確認する対象です。

ツールバーの文字装飾にはブラウザの `contenteditable` / `execCommand` を使用しています。`execCommand` は非推奨APIのため、ブラウザを更新する際は編集操作を確認してください。[MDNのAPI資料](https://developer.mozilla.org/en-US/docs/Web/API/Document/execCommand)
# 下書きの管理

「下書き一覧」から記事を切り替えられます。「新しい記事」や記事の読み込みでは、編集中の原稿を保存してから別の下書きを作ります。保存できない場合は切り替えを止めます。

保存履歴は1分ごと、または手動保存時の変更前の原稿を直近10件まで保持します。履歴の復元は別の下書きになり、現在の原稿も残ります。別タブとの保存が衝突した場合も、今の原稿を別の下書きとして保存します。従来の下書きは初回起動時に引き継ぎます。

画像のデータは本文と分けて保存するため、文章を打つたびに画像全体を書き直しません。保存先はこのブラウザです。別の端末へ移す場合はZIPを書き出してください。
# 公開済みの記事を開く

「記事を開く」→「公開済みの記事から選ぶ」から、サイトの記事を一覧で選べます。本文・記事情報・同じサイトの画像を取得し、別の下書きとして開きます。画像を取得できなかった場合は表示される案内に従って追加してください。外部サイトの画像は元のURLを維持します。
