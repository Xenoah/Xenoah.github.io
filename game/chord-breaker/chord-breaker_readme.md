# CHORD BREAKER

ブロック崩しとコード進行を組み合わせたミニゲームです。

- ブロックには `C`, `Am`, `F`, `G7` などのコードが割り当てられています。
- ブロックに当たると、そのコードが現在のコード進行に追加されます。
- 研究ベースの遷移確率を `chord-probabilities.json` に保存し、次に気持ちいいコードを「特売」候補として案内します。
- 特売候補や気持ちいい進行を叩くと、ブロックHPを大きく削れます。
- 度し難い進行を踏むと `COLLAPSE` ゲージが上がり、一定値で盤面のブロックが絶えます。
- プレイヤーHPは3。ゲームはエンドレスで、コンボが決まるとHP回復抽選が入ります。
- 難しいモードや高テンション状態では、コンボ回復が起きにくくなります。
- POP / JAZZ / CHAOS の3モードがあります。

## Harmony Data

`chord-probabilities.json` の確率は、論文・書籍の知見をゲーム向けに正規化したものです。個別の進行ごとに実験値が直接測られている、という意味ではありません。

参照した考え方:

- Krumhansl & Kessler (1982): 調性感・トニック安定性
- Lerdahl (2001/2005): Tonal Pitch Space による距離、緊張、引力
- Vega (2003): 緊張と引力の知覚的な逆相関
- Huron (2006): 期待、驚き、解決後の評価

Web Audio API でコード音を鳴らすため、音はユーザー操作後に再生されます。GitHub PagesではJSONを読み込みます。ローカルでHTMLを直接開いてJSON読込が失敗した場合は、内蔵フォールバック確率で動作します。
