# CHORD BREAKER

ブロック崩しとコード進行を組み合わせたミニゲームです。

- ブロックには `C`, `Am`, `F`, `G7` などのコードが割り当てられています。
- ブロックに当たると、そのコードが現在のコード進行に追加されます。
- `C -> Am -> F -> G7 -> C` や `Dm7 -> G7 -> C` のような自然な進行は、パドル拡大・減速・グルーヴ上昇で遊びやすくなります。
- 借用和音や遠いコードを急に踏むと高得点ですが、テンションが上がってボールが速くなります。
- POP / JAZZ / CHAOS の3モードがあります。

Web Audio API でコード音を鳴らすため、音はユーザー操作後に再生されます。
