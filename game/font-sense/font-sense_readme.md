# ABSOLUTE FONT SENSE

## 基本情報

- 配置場所: `game/font-sense/font-sense.html`
- 公開時のリンク: `https://xenoah.github.io/game/font-sense/font-sense.html`
- ジャンル: 絶対フォント感トレーニング / フォント名当てクイズ
- 実装形式: HTML / CSS / JavaScript の単体ページ

## ゲーム概要

表示された文字サンプルの字形を見て、正しいフォント名を選ぶミニゲームです。

ブラウザ上で判別できるローカルフォントを自動検出し、環境ごとに成立しやすい出題プールを作ります。
難易度ごとにラウンド数、選択肢数、制限時間、出題プール数が変化します。

## 主な機能

- EASY / NORMAL / EXPERT の3モード
- 難易度はフォントのメジャー度、同系統バリアント、見分けにくい書体クラスタを加味
- フォント名4択または6択クイズ
- 著作権切れ作品からの日本語文と、ゲーム用英訳のランダム表示100通り
- Windows標準・Office系・日本語書体を中心にしたフォント候補100件
- ブラウザで検出できたフォントだけを出題対象にする
- 制限時間つきスコアリング
- Web Audio API による正解・不正解・操作時の効果音
- 正解時・不正解時の判定モーダル表示
- JP / EN の言語切替と、日本語モードでのフォント日本語名称優先表示
- コンボ、正答率、ベストスコア保存
- 出題対象フォント一覧
- ミスしたフォントの結果表示
- キーボード入力: `1` から `6`、`Enter`、`Escape`

## モード別パラメータ

| モード | ラウンド数 | 選択肢数 | 制限時間 | 出題プール | 基礎点 | 出題傾向 |
| --- | --- | --- | --- | --- | --- | --- |
| EASY | 10 | 4択 | 36秒 | 18書体 | 100 | メジャー書体・字形がはっきり違うもの中心 |
| NORMAL | 14 | 4択 | 28秒 | 42書体 | 130 | 一般的な書体＋似た選択肢を混在。偶数ラウンドでは見分けにくい書体を優先出題 |
| EXPERT | 18 | 6択 | 22秒 | 88書体 | 180 | マイナー書体・近縁バリアント。本文の太さ・字間にランダムなノイズを付加 |

出題プールは検出済みフォントから構成され、フォントのメジャー度・同系統バリアント・見分けにくい書体クラスタ（`CONFUSABLE_GROUPS`）を加味してグループ均等にサンプリングします。直近2問に出た書体は連続出題を避けます。EASY では字形がはっきり違う（同系統の紛らわしい書体を持たない）メジャー書体を優先的に出題します。

検出フォント数がプール数に満たない環境では、モードカードに実際のプール数と `(max)` を表示します。モードに必要な選択肢数すら満たせない場合、そのモードは選択不可になります。

## スコア計算

正解時のみ加点します。

- 加点 = 基礎点（モード依存）＋ タイムボーナス ＋ コンボボーナス
- タイムボーナス = `(残り時間 / 制限時間) ^ 1.4 × 80`（最大80点、速答ほど伸びる）
- コンボボーナス = `コンボ数 × 12`（最大90点）
- 不正解・時間切れでコンボはリセット

## 評価ランク

リザルトでは正答率に応じて S / A / B / C / D を表示します。

- S: 正答率 95% 以上
- A: 82% 以上
- B: 68% 以上
- C: 50% 以上
- D: 50% 未満

## フォント検出ロジック

`<canvas>` の `measureText` で対象フォントの描画幅を serif / sans-serif / monospace の各フォールバックと比較し、幅が変化する（=実際に適用された）書体だけを出題対象にします。
検出に失敗しても、`Arial` / `Georgia` / `Times New Roman` / `Courier New` / `Verdana` / `Impact` は必ず候補に追加されます。
候補フォント定義（`FONT_DEFS`）は Windows 標準・Office 系・日本語書体を中心に約100件、各書体は `Sans` / `Serif` / `Mono` / `Display` / `Japanese` などの `group` で分類されています。

太さ違いバリアント（Light / Semilight / Semibold / Medium / Black / Demibold）は、字幅が基底書体と変わらず未インストールでもブラウザが基底へフォールバックして検出されてしまうことがあります。これらは字幅で基底と区別できない場合、出題の公平性のため候補から除外します（ベストエフォートのヒューリスティック。Canvas のみでは太さ違いを厳密には判別できないため、視覚的に区別できる太さ違いも除外され得ます）。

## 画面構成と UI

- スタート画面: HERO（検出フォントが飛び交うオープニング演出）、モード選択、BEST / MAX COMBO / FONTS のスタッツ、FONT LIST 導線
- ゲーム画面: HUD（ROUND / SCORE / COMBO / ACCURACY / MODE）、タイマーバー、出題カード（日本語・英語サンプル＋出典）、選択肢、サイドの FONT RADAR
- FONT RADAR: 実際に出題された／ミスした書体を、ミス回数・出題回数の多い順に最大7件表示（出題頻度バー＋ミス回数 `-n`）
- 判定モーダル: 正解時は正解書体カード、不正解時は「選択した書体」と「正解書体」を並べて比較。各カードには書体グループ（セリフ／サンセリフ等）の特徴コメントを表示
- リザルト画面: 評価ランク、スコア、正答率、最大コンボ、MISS CHECK（ミス書体の一覧）
- FONT LIST 画面: 検出済み全書体のプレビュー（`Ag 永`）と名称・グループ

## 操作

- 文字サイズ切替: 小 / 中 / 大
- 言語切替: JP / EN（日本語モードではフォントの日本語名称を優先表示）
- SFX: 効果音 ON / OFF（Web Audio API。正解は上昇アルペジオ、不正解は低音、操作音）
- HOME / RESTART ボタン
- キーボード: `1`〜`6` で解答（メインキー・テンキー両対応、IME入力中は無視）、`Enter` で次の問題、`Escape` でホームへ／モーダルを閉じる

## 復習機能

ミスした書体は `localStorage`（`weakFonts`）にミス回数として蓄積され、次回以降のプレイで一定確率（約30%）で優先的に再出題されます。正解できた書体は重みが徐々に下がり、繰り返し誤答する書体ほど出やすくなります。

## フォントの取得とオン/オフ設定

出題対象フォントは2系統で集めます。

1. **Canvas 検出（全ブラウザ）** — `FONT_DEFS`（約100件）のうち、`measureText` で実際に描画できる書体だけを初期候補にします。
2. **全フォント自動取得（Chrome / Edge）** — Local Font Access API（`window.queryLocalFonts()`）で、PC にインストールされた全フォントファミリーを取得します。初回はブラウザの許可ダイアログが出ます。一度許可すると、次回以降は自動で読み込みます。非対応ブラウザでは 1 のみで動作します。

自動取得したファミリーのうち、`FONT_DEFS` に定義済みのものは日本語名称・グループ・紛らわしい書体クラスタの情報を引き継ぎます。未定義のファミリーは名前からセリフ／サンセリフ／等幅／手書き等を推定して分類します。

⚙ FONTS ボタンの設定パネルで、ファミリーごとに出題のオン/オフを切り替えられます。

- 「全フォントを読み込む」: Local Font Access API で全フォントを取得
- 「全て有効 / 全て無効」: 一括切替
- 検索ボックス: フォント名・日本語名で絞り込み
- 各行のチェックボックス: 個別のオン/オフ（`localStorage` に保存）

大量のフォントを表示する設定パネルとフォント一覧は `content-visibility: auto` で画面外の描画を省き、表示負荷を抑えています。

## 表示テーマ

OS の配色設定（`prefers-color-scheme`）に追従し、ライト／ダークの両テーマに対応します。

## 保存仕様

`localStorage`（キー: `absolute-font-sense-v1`）に以下を保存します。

- 最後に選んだモード（`mode`）
- ベストスコア（`bestScore`）
- 最大コンボ（`bestCombo`）
- 文字サイズ（`textSize`）
- 言語設定（`language`）
- 効果音 ON/OFF（`sfxEnabled`）
- 苦手書体のミス回数（`weakFonts`、復習出題に使用）
- 無効化したフォント（`disabledFonts`）
- 全フォント読み込み済みフラグ（`fontsLoaded`）

## 技術構成

- 依存ライブラリなしの単一 HTML ファイル（HTML / CSS / JavaScript を内包）
- ローカルフォント検出に Canvas API、効果音に Web Audio API を使用
- 全フォント自動取得に Local Font Access API（`queryLocalFonts` / Chrome・Edge、セキュアコンテキスト必須）。非対応ブラウザは Canvas 検出にフォールバック
- `prefers-reduced-motion` に対応し、アニメーションを抑制
- `prefers-color-scheme` に対応し、ライト／ダークテーマを自動切替
- SEO 向けに OGP / Twitter Card / JSON-LD（`WebApplication`）メタデータを設定済み
