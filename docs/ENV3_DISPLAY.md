# 百葉箱の最新値表示

トップページは次の読み取り専用APIを1分ごとに確認します。

https://xenoah-weather-api.xenoah.chatgpt.site/api/latest

元のGAS URLはAPIサーバーの秘密設定だけに保存します。公開するのは気温・湿度・気圧と記録時刻の4項目です。デバイス名、Wi-Fi情報、稼働時間、書込み用合言葉は返しません。元の接続先や合言葉をこのリポジトリ、HTML、JavaScript、ログ、PRへ記載しないでください。

## 表示とデータの契約

- 正常: `ok: true` の `data` 内に `timestamp`, `temperature_c`, `humidity_pct`, `pressure_hpa` が入る。
- 値は数値または `null`、時刻はタイムゾーン付きISO 8601。元GASの時刻は測定時刻ではなく、サーバーが受信した時刻。
- 記録待ち: `{"ok":false,"error":"no data"}`。空欄と送信待ちを表示する。実測値の代わりにデモ値を本番へ置かない。
- 未設定: `{"ok":false,"error":"not configured"}` を返す場合は表示枠を隠す。
- 古い記録: 30分を超えると「現在の値とは限りません」と表示する。機器の送信間隔に合わせ、include の `data-stale-minutes` を変更する。
- 失敗: 前回の成功値があれば記録時刻と失敗案内を残す。初回失敗なら空欄にする。未取得や `null` を0と表示しない。
- 非表示タブでは通信せず、戻ったときに再取得。手動更新もできる。

APIは30秒だけキャッシュします。機器の送信間隔は別で、既定10分（M5の設定画面で1〜60分に変更可）です。画面更新が1分でも、機器が送信しなければ値は新しくなりません。APIは記録時刻を現在時刻に置き換えません。

## 公開境界

GitHub Pagesは静的配信です。難読化やブラウザ向け環境変数では秘密を守れません。ブラウザは上記の固定公開APIだけを読み、他のURL・クエリ・リダイレクトを拒否します。これは誤った接続先への通信を防ぐもので、HTMLへ書かれた秘密の公開そのものは防ぎません。コミット前に秘密が含まれていないことを必ず確認します。

中継APIはGET以外の書込み、任意URLへの転送、期間取得などのパラメータを受け付けません。上流のエラー本文、ヘッダー、リダイレクト、URLを返さず、キャッシュするのも抽出済み4項目だけです。CORSはホームページのoriginを許可しますが、認証ではありません。この4項目は誰でも読める公開情報です。

元APIは読み書きが同じURLなので、非公開扱いを維持したうえで書込み認証も設定することを推奨します。GASのスクリプトプロパティ `TOKEN` と、M5の設定画面にある各送信先の「合言葉」を同じ値にします。片側だけ変えると送信が拒否されるため、続けて両側を更新してください。ファームウェア書換えは不要です。読み出し認証を別途変更する場合、中継側の対応も必要です。

## 検査

```sh
npm --prefix blog test
node scripts/check-site.js
```

Jekyllで `_site` をビルドしてからブラウザ検査を実行します。ブラウザ検査は公開APIをモックし、非公開の接続先へ通信しません。

```sh
npm --prefix blog run test:browser -- env3.spec.cjs
```
