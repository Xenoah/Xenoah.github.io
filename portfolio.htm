Project Name：XNH_news-atlas / World News Map Viewer

Web AppMapGitHub Actions公開中
概要：
世界ニュースを地図上に可視化する静的Webアプリ。ニュース記事、災害・地震・自然イベントなどを地理情報と結び、時間・カテゴリ・検索で絞り込めるようにする試み。
何を作ったか
MapLibre GL JSを使ったダークテーマの世界地図UI、ニュースイベント一覧、ヒートマップ、トレンド表示、静的JSONデータ更新フロー。
Problem：
ニュースは記事単位では追えても、「どこで何が起きているか」を地図・時間軸・カテゴリで俯瞰しづらい。ブラウザだけで見られる形にしたかった。
Role：
企画、要件定義、UI方針、AI実装指示、動作確認、GitHub Pages公開、改善点整理。
Tech：
HTML / CSS / JavaScript / MapLibre GL JS / Python / GitHub Actions / RSS / GeoRSS / GeoJSON / Static JSON
AI Use：
UI構成、データ処理、スコアリング、README整理、デバッグ候補の洗い出しに利用。地図として何を見せたいか、公開方針、検証判断は本人側で実施。
What worked：
バックエンドなしでGitHub Pagesに公開できる構成にできた。地図、リスト、時間フィルタ、カテゴリ表示の関係が作品として見える。
What failed：
ニュースの位置推定精度、非ジオタグ記事の扱い、データ量、ソース偏りが課題。世界地図化は見栄えが良い反面、誤配置すると説得力が落ちる。
Next：
位置情報の信頼度表示、ソース別フィルタ、モバイルUI改善、非ジオタグ記事のレビュー導線を強化したい。

Project Name：XNH WebApp PDF Editor

PDFVanilla JSLocal Processing公開中
概要：
ブラウザだけでPDFを読み込み、表示、ページ編集、注釈追加、保存まで行うローカル処理完結型のPDFエディタ。
何を作ったか
PDF読み込み、ページサムネイル、ページ並び替え、削除、回転、結合、抽出、図形・テキスト注釈、Undo / Redo、保存処理を持つWebアプリ。
Problem：
ちょっとしたPDF編集で外部サービスへファイルを投げたくない。ローカル完結で、ビルドなしですぐ起動できる道具が欲しかった。
Role：
要件整理、UI動線設計、AI実装指示、機能検証、README整理、ローカル処理方針の確認。
Tech：
HTML / CSS / JavaScript / pdf.js / pdf-lib / Canvas / GitHub Pages
AI Use：
実装案、UI整理、エラー対策、PDF編集方式の文章化に利用。PDFの扱い方、外部送信しない方針、最終確認は本人が担当。
What worked：
npm install不要、CDN非依存、静的ホスティングで動く構成にできた。PDFを外に送らず処理する思想も明確に出せた。
What failed：
PDF本文はWordのような文字データではなく描画命令の塊なので、意味的な全文編集は難しい。見た目を焼き込む方式との割り切りが必要だった。
Next：
注釈操作の安定化、スマホUI、保存前プレビュー、操作説明の追加。PDF編集は沼なので、沼底の看板も立てる。

Project Name：DTMF Converter / DTMFの仕組み

SignalWeb AudioStudy公開中
概要：
電話のプッシュ音で使われるDTMFを、周波数の組み合わせとして理解・実装するためのWeb系学習プロジェクト。
何を作ったか
DTMFの低群/高群周波数、生成、検出、Goertzel法やWeb Audio APIでの扱いを整理した実装・解説ページ。
Problem：
音声信号処理は見えにくい。ボタン音を周波数・判定条件として分解し、Web上で理解できる形にしたかった。
Role：
技術調査、仕様整理、AI支援による文章・実装補助、動作確認。
Tech：
HTML / CSS / JavaScript / Web Audio API / DTMF / 周波数解析
AI Use：
DTMF仕様の整理、検出ロジックの候補、説明文の構成に利用。式・周波数・判定条件は確認しながら整理。
What worked：
単なる便利ツールではなく、通信・信号処理の学習ログとして置ける。電子工作/FA寄りの関心とも接続できる。
What failed：
生成は比較的簡単だが、検出はノイズ、しきい値、twist、継続時間の判定が効く。現実の音声はおとなしくない。
Next：
実マイク入力での検出安定化、スペクトラム表示、誤検出ログの可視化。
