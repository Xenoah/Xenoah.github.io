# Audio to Arduino tone()

MP3 / WAVなどの音声をブラウザ内で解析し、Arduinoの`tone()`関数で再生できる単音メロディースケッチへ変換するツールです。

## ファイル

- `audio-to-arduino-tone.htm`: ツール本体（外部ライブラリ不要）

## 主な機能

- MP3 / WAVを含むブラウザ対応音声の読み込み
- 波形表示
- 解析前の元音声の再生、一時停止、停止、シーク
- FFTのスペクトルピークと最大4倍音による主旋律候補抽出
- 動的計画法による前後の音程連続性を考慮したメインメロディー追跡
- 音源を高・中・低の声部が重なった多層構造として分離
- 上声部・中声部・低声部・自動判定から抽出対象を選択
- 層をまたいだコード構成音への乗り移りを抑える分離強度設定
- 15種類の解析方式を選択可能
  - 多層アンサンブル
  - コード除外メロディー
  - 上声部アンサンブル
  - 複数方式比較・自動選択
  - 倍音加算
  - HPS（倍音積）
  - 基音ピーク
  - サブハーモニック加算
  - 奇数倍音強調
  - 倍音豊富な楽器向け
  - 安定追従
  - 高速メロディー追従
  - 最高音優先
  - ベースライン抽出
  - フレーム最大候補
- 元音声波形、上位1〜5本の音程候補、確定メロディーの可視化
- 可視化範囲を5・10・30・60秒から選択して移動表示
- 1ms〜200msの解析時間分解能
- 半音単位への量子化、短いノートの統合
- 無音区間を休符として変換
- 変換結果のブラウザ試聴
- `PROGMEM`を使ったArduinoスケッチ生成
- コードのコピー、`.ino`ダウンロード
- 解析は完全にクライアントサイド

## 使い方

1. 音声ファイルをドロップまたは選択する
2. 時間分解能、無音しきい値、音域などを調整する
3. 「音程を解析してArduinoコードを生成」を押す
4. 試聴して結果を確認する
5. コードをコピーするか`.ino`として保存する

## 変換方式と制約

`tone()`は基本的に単音矩形波の出力です。このツールは音声を短時間フレームに分割し、各区間で最も強い主音程を推定して半音単位へ丸めます。

そのため、次の素材に向いています。

- 単音のシンセサイザー
- 口笛
- ハミング
- 主旋律だけの演奏
- ビープ音

次の素材は正確に変換できない場合があります。

- 和音や複数楽器を含む曲
- ドラムが強い曲
- ノイズの多い録音
- ビブラートや装飾音が多い歌声
- 低音と高音が同時に鳴る素材

解析時間とメモリ使用量を抑えるため、変換対象は時間分解能に応じて先頭60〜180秒までです。1msでは先頭60秒、2〜4msでは先頭120秒、それ以上では先頭180秒を解析します。

## Arduino側

生成コードはAVR系Arduino（UNO / Nanoなど）を主対象とし、周波数配列と長さ配列を`PROGMEM`へ保存します。圧電ブザーは指定したデジタルピンとGNDへ接続します。スピーカーや大音量のブザーを直接GPIOへ接続せず、必要に応じて抵抗・トランジスタ・アンプを使用してください。
